# Математика: рывок

Мобильное приложение для подготовки к ОГЭ и ЕГЭ по математике. Доступны восемь базовых тем и четырнадцать разделов ОГЭ №6–19. В каждой теме есть три коротких объяснения и ровно 200 разных задач в 10 группах по 20. Из выбранной группы тренировка случайно берёт 10 задач: сначала карточки с ответами, затем те же 10 без ответов в другом порядке. Фон карточки выбирается из 20 приглушённых цветов и сохраняется для этой задачи на обоих этапах. Сложение и вычитание в быстром счёте остаются в пределах 200. Результаты и рекорды по темам сохраняются локально. [Основа геометрических разделов и источники ФИПИ](docs/OGE-GEOMETRY.md). [Темы №11–15 по присланным подборкам](docs/OGE-11-15.md). [Уравнения и вероятность №9–10](docs/OGE-9-10.md). [Вычисления, сравнение и выражения №6–8](docs/OGE-6-8.md).

Модуль «Простой счёт» предлагает сложение и вычитание от 0 до 20: сначала до 5, затем до 10, 15 и 20. У групп есть названия, у каждой задачи — простой приём счёта.

Все 1800 задач алгебры №6–14 проверены 17 октября 2026 года: уточнены условия, формат корней, запись дробных коэффициентов и показ ответов. [Результаты проверки и границы соответствия экзамену](docs/ALGEBRA-REVIEW.md).

Добавлены личное повторение ошибок, подробный прогресс и подсказки в три шага. Ошибки и задачи с помощью сохраняются сразу; для закрепления нужны три самостоятельных повторения с интервалами. Прогресс показывает точность, решения без подсказок и охват групп. Прежние рекорды переносятся автоматически. [Как работают новые функции](docs/LEARNING.md).

В практической части ОГЭ №1–5 теперь восемь модулей: квартиры, участки, путешествия по клеткам, дороги без сетки, шины, мобильная связь, печи для бани и листы бумаги. В каждом 40 связанных вариантов (200 вопросов), десять групп и собственные схемы/графики с таблицами и решениями. Всего 320 вариантов и 1600 вопросов. За тренировку выбираются два целых блока, вопросы идут по порядку №1–5. [Состав, проверки и источники](docs/OGE-1-5.md).

Модуль «Квадраты и корни · 11–99» содержит все 89 квадратов и 89 обратных корней (√121…√9801), плюс 22 закрепляющих задания — 200 карточек в десяти группах по диапазонам чисел.

Модуль «Простые дроби → десятичные»: 280 карточек, 14 групп по 20, все дроби со знаменателями 2–16 от 1/16 до 17/8, включая сокращаемые. Дроби отображаются с горизонтальной чертой; общая памятка с выбором знаменателя доступна в уроке, группах и обеих фазах тренировки. Период вводится в скобках (например, 0,1(6)); ответы проверяются точно, без округления.

## Запуск

Добавлены три режима: **«Пробный экзамен»** (полная работа №1–25, таймер, навигация, черновики, история и разбор после сдачи), **«Справочник формул»** (40 карточек с визуальными пояснениями, примерами, проверкой и избранным) и **«Найди ошибку»** (200 решений, поиск неверного шага и его исправление). [Поведение, оценивание и проверки](docs/STUDY-TOOLS.md).

Вторая часть ОГЭ №20–25: шесть модулей по 200 задач, 10 групп по 20, случайная подборка десяти. Есть геометрические рисунки, построения графиков, сохраняемый черновик, подсказки, полные решения, чек-листы и интервальное повторение. Полнота решения оценивается учеником или преподавателем; числовой итог проверяется отдельно. [Типы задач, источники и границы проверки](docs/OGE-PART2.md).

Нужен Node.js 22.13+ и Expo Go на телефоне.

```bash
npm ci
npm start
```

Откройте показанный QR-код в Expo Go. Для проверки кода: `npm run typecheck`, `npm test`. Для веб-версии при необходимости установите совместимые зависимости командой `npx expo install react-dom react-native-web @expo/metro-runtime`, затем `npm run web`.

## APK и обновления

На главной доступен режим «Есть пять минут»: счёт, повторение знакомых тем и прошлые ошибки в одной сохраняемой подборке. После ответа можно открыть проверенный разбор и задать вопрос нейросетевому помощнику после подключения преподавателем. Сервер и настройка описаны в [docs/DAILY-ASSISTANT.md](docs/DAILY-ASSISTANT.md).

Каждый push в `main` запускает проверки и сборку Android APK через GitHub Actions. Успешная сборка прикрепляется к новому выпуску в разделе [Releases](https://github.com/Tombstone1922/math-sprint-oge-ege/releases) как `app-release.apk`. Установите APK на Android через браузер или файловый менеджер.

Приложение проверяет новые выпуски при открытии и возвращении на экран и предлагает скачать новый APK. Для проверки выпусков без входа в GitHub репозиторий должен быть публичным. Установка проходит через системный установщик Android и требует подтверждения пользователя. OTA через EAS требует отдельной конфигурации Expo и описано в [docs/RELEASES.md](docs/RELEASES.md). Текущие APK подписаны тестовым ключом Expo; для долгосрочной публикации потребуется защищённый постоянный ключ подписи.

## Структура

- `src/app/` — экраны каталога, урока, выбора группы, карточек, практики и результата.
- `src/content.ts` — каталог модулей, привязка к экзаменам и содержание урока.
- `src/engine.ts`, `src/module-problems.ts` — банки примеров, выбор раунда и проверка чисел и дробей.
- `src/oge11-problems.ts` … `src/oge15-problems.ts` — по 200 задач на графики, формулы, неравенства, последовательности и геометрию; графики и числовые прямые рисуются в `src/algebra-figures.tsx`.
- `src/oge16-problems.ts`, `src/oge17-problems.ts`, `src/analytic-geometry.ts` — по 200 задач №16 и №17 в тематических группах по присланным PDF; геометрические рисунки, подробные решения и десятичный ввод.
- `src/oge18-problems.ts`, `src/grid-geometry.ts`, `src/grid-figure.tsx` — 200 задач №18 с точными чертежами: данные считываются по клеткам, десять групп выделены по типам задач.
- `src/progress.tsx` — локальное сохранение результатов.
- `src/extended/` — банки №20–25, графики, решения и отдельная статистика самооценки; экраны `extended` и `extended-practice`.
- `src/study/` — полный пробник, справочник и поиск ошибок; их сохранение и связь с очередями повторения.
- `src/update-checker.tsx` — проверка и применение загруженного обновления.

Геометрия привязана к номерам ОГЭ‑2026 и проекта ОГЭ‑2027. Для второй части есть учебная самопроверка по подробному образцу. Следующие шаги: редактор учебного контента, проверка на реальных устройствах и сборки для магазинов.
