# Математика: рывок

Мобильное приложение для подготовки к ОГЭ и ЕГЭ по математике. Первая версия посвящена быстрому устному счёту: короткий урок с приёмами, шесть карточек с готовым ответом, затем десять заданий без подсказанного ответа. Ошибочные примеры повторяются в конце; статистика сохраняется локально.

## Запуск

Нужен Node.js 22.13+ и Expo Go на телефоне.

```bash
npm ci
npm start
```

Откройте показанный QR-код в Expo Go. Для проверки кода: `npm run typecheck`, `npm test`. Для веб-версии при необходимости установите совместимые зависимости командой `npx expo install react-dom react-native-web @expo/metro-runtime`, затем `npm run web`.

## CI/CD и обновления устройств

GitHub Actions проверяет PR и коммиты в `main`. Из вкладки Actions можно вручную заказать установочную сборку (`Build installable app`) и отправить обновление (`Release OTA update`) в канал `preview` или `production`. Настройка Expo и первого выпуска подробно описана в [docs/RELEASES.md](docs/RELEASES.md).

Обновления кода и ресурсов загружаются через EAS Update. На устройстве должна стоять сборка, сделанная **после подключения EAS Update** и подписанная на соответствующий канал; обычный запуск проекта через Expo Go не является такой установкой. Обновление проверяется при открытии приложения и при возвращении к нему; после загрузки приложение предлагает перезапуск. Изменения нативных библиотек требуют новой установочной сборки.

## Структура

- `src/app/` — экраны каталога, урока, карточек, практики и результата.
- `src/content.ts` — каталог модулей, привязка к экзаменам и содержание урока.
- `src/engine.ts` — набор примеров и проверка ответов.
- `src/progress.tsx` — локальное сохранение результатов.
- `src/update-checker.tsx` — проверка и применение загруженного обновления.

Модули «Проценты», «Дроби», «Уравнения» пока показаны в каталоге как планы развития. Привязка к конкретным номерам экзамена потребует выбора года, уровня и актуального спецификатора; приложение не обещает такую привязку до наполнения материалов. Следующие шаги: редактор учебного контента, полноценная карта заданий ОГЭ/ЕГЭ, персональные повторы, проверка на реальных устройствах и сборки для магазинов.
