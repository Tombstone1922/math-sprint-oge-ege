# Математика: рывок

Мобильное приложение для подготовки к ОГЭ и ЕГЭ по математике. Доступны восемь базовых тем и девять разделов ОГЭ №11–19. В каждой теме есть три коротких объяснения и ровно 200 разных задач в 10 группах по 20. Из выбранной группы тренировка случайно берёт 10 задач: сначала карточки с ответами, затем те же 10 без ответов в другом порядке. Фон карточки выбирается из 20 приглушённых цветов и сохраняется для этой задачи на обоих этапах. Сложение и вычитание в быстром счёте остаются в пределах 200. Результаты и рекорды по темам сохраняются локально. [Основа геометрических разделов и источники ФИПИ](docs/OGE-GEOMETRY.md). [Темы №11–15 по присланным подборкам](docs/OGE-11-15.md).

Модуль «Простой счёт» предлагает сложение и вычитание от 0 до 20: сначала до 5, затем до 10, 15 и 20. У групп есть названия, у каждой задачи — простой приём счёта.

## Запуск

Нужен Node.js 22.13+ и Expo Go на телефоне.

```bash
npm ci
npm start
```

Откройте показанный QR-код в Expo Go. Для проверки кода: `npm run typecheck`, `npm test`. Для веб-версии при необходимости установите совместимые зависимости командой `npx expo install react-dom react-native-web @expo/metro-runtime`, затем `npm run web`.

## APK и обновления

Каждый push в `main` запускает проверки и сборку Android APK через GitHub Actions. Успешная сборка прикрепляется к новому выпуску в разделе [Releases](https://github.com/Tombstone1922/math-sprint-oge-ege/releases) как `app-release.apk`. Установите APK на Android через браузер или файловый менеджер.

Приложение проверяет новые выпуски при открытии и возвращении на экран и предлагает скачать новый APK. Для проверки выпусков без входа в GitHub репозиторий должен быть публичным. Установка проходит через системный установщик Android и требует подтверждения пользователя. OTA через EAS требует отдельной конфигурации Expo и описано в [docs/RELEASES.md](docs/RELEASES.md). Текущие APK подписаны тестовым ключом Expo; для долгосрочной публикации потребуется защищённый постоянный ключ подписи.

## Структура

- `src/app/` — экраны каталога, урока, выбора группы, карточек, практики и результата.
- `src/content.ts` — каталог модулей, привязка к экзаменам и содержание урока.
- `src/engine.ts`, `src/module-problems.ts` — банки примеров, выбор раунда и проверка чисел и дробей.
- `src/oge11-problems.ts` … `src/oge15-problems.ts` — по 200 задач на графики, формулы, неравенства, последовательности и геометрию; графики и числовые прямые рисуются в `src/algebra-figures.tsx`.
- `src/oge16-problems.ts`, `src/oge17-problems.ts`, `src/analytic-geometry.ts` — по 200 задач №16 и №17 в тематических группах по присланным PDF; геометрические рисунки, подробные решения и десятичный ввод.
- `src/oge18-problems.ts`, `src/grid-geometry.ts`, `src/grid-figure.tsx` — 200 задач №18 с точными чертежами: данные считываются по клеткам, десять групп выделены по типам задач.
- `src/progress.tsx` — локальное сохранение результатов.
- `src/update-checker.tsx` — проверка и применение загруженного обновления.

Геометрия первой части привязана к номерам ОГЭ‑2027 по проекту ФИПИ. Задания с развёрнутым решением №23–25 пока не представлены в режиме автоматической проверки. Следующие шаги: редактор учебного контента, персональные повторы, проверка на реальных устройствах и сборки для магазинов.
