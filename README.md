# Математика: рывок

Мобильное приложение для подготовки к ОГЭ и ЕГЭ по математике. Доступны семь тем: быстрый счёт, проценты, дроби, уравнения, геометрия, степени и корни, вероятность. В каждой теме есть три коротких объяснения и банк задач. Тренировка выбирает 10 примеров: сначала карточки с ответами, затем те же 10 без ответов в другом порядке. У быстрого счёта отдельный пул из 100 примеров сложения и вычитания в пределах 200. Результаты и рекорды по темам сохраняются локально.

## Запуск

Нужен Node.js 22.13+ и Expo Go на телефоне.

```bash
npm ci
npm start
```

Откройте показанный QR-код в Expo Go. Для проверки кода: `npm run typecheck`, `npm test`. Для веб-версии при необходимости установите совместимые зависимости командой `npx expo install react-dom react-native-web @expo/metro-runtime`, затем `npm run web`.

## APK и обновления

Каждый push в `main` запускает проверки и сборку Android APK через GitHub Actions. Успешная сборка прикрепляется к новому выпуску в разделе [Releases](https://github.com/Tombstone1922/math-sprint-oge-ege/releases) как `app-release.apk`. Установите APK на Android через браузер или файловый менеджер.

Приложение проверяет новые выпуски при открытии и возвращении на экран и предлагает скачать новый APK. Для проверки выпусков без входа в GitHub репозиторий должен быть публичным. Установка проходит через системный установщик Android и требует подтверждения пользователя. OTA через EAS требует отдельной конфигурации Expo и описано в [docs/RELEASES.md](docs/RELEASES.md). Текущие APK подписаны тестовым ключом Expo; для долгосрочной публикации потребуется защищённый постоянный ключ подписи.

## Структура

- `src/app/` — экраны каталога, урока, карточек, практики и результата.
- `src/content.ts` — каталог модулей, привязка к экзаменам и содержание урока.
- `src/engine.ts`, `src/module-problems.ts` — банки примеров, выбор раунда и проверка чисел и дробей.
- `src/progress.tsx` — локальное сохранение результатов.
- `src/update-checker.tsx` — проверка и применение загруженного обновления.

Привязка к конкретным номерам экзамена потребует выбора года, уровня и актуального спецификатора; текущие модули сгруппированы по темам. Следующие шаги: редактор учебного контента, карта заданий ОГЭ/ЕГЭ, персональные повторы, проверка на реальных устройствах и сборки для магазинов.
