# Ошибки, прогресс и подсказки

Добавлены три функции для самостоятельной работы. Все данные хранятся на устройстве, без аккаунта и сервера.

## Повторение ошибок

Ошибочный ответ записывается сразу после проверки, до завершения раунда. Открытая подсказка или общая памятка дробей также добавляет задачу на закрепление, даже если ученик ещё не отправил ответ.

На главной странице доступен раздел «Повторить ошибки». В нём есть вкладки «Сейчас» и «Все», группировка по модулям и группам, состояние каждой задачи и время следующего повторения. Один раунд содержит от одной до десяти доступных задач одной группы. Ответы перед повторением не показываются. Вопросы ОГЭ №1–5 сохраняют общее условие, таблицы и рисунок даже при повторении одного вопроса.

Для завершения цикла нужны три правильных ответа без подсказок в режиме повторения:

1. Первый повтор доступен сразу после ошибки.
2. После первого успеха задача возвращается через 24 часа.
3. После второго — ещё через 72 часа. Третий успех завершает цикл.

Ошибка или помощь сбрасывает этот цикл. Обычная тренировка и преждевременное открытие старого адреса повторения не перескакивают через интервалы. После одного успеха задача остаётся во вкладке «Все». Новая ошибка после завершённого цикла вновь добавляет её в очередь. Счётчик успешных циклов накопительный.

## Личный прогресс

На главной странице, в выборе группы и на экране результата появились переходы к подробному прогрессу. Учёт ведётся по каждому модулю и группе, включая незавершённые раунды:

- «Верных ответов» — доля правильных проверенных ответов, в том числе с подсказкой.
- «Без подсказок» — доля правильных ответов без помощи в самостоятельной части тренировки.
- «Ответов с помощью» — число проверенных ответов, перед которыми открывалась помощь.
- Охват — число разных попробованных задач. Повтор одной задачи не увеличивает охват.
- Группа помечается пройденной после попытки решить все её задачи; это не утверждение о полном освоении. Точность показана отдельно.
- Рекомендации выделяют группы с менее чем 80% самостоятельных правильных ответов после хотя бы трёх попыток.

Результат обычной десятки показывает самостоятельные ответы, верные ответы с помощью и ошибки отдельно. Короткие повторы имеют собственный знаменатель и счётчик сессий; результат 1/1 не заменяет рекорд обычной тренировки из десяти задач.

## Подсказки

В самостоятельной тренировке помощь открывается последовательно: идея, первый шаг, полное решение. Первые два уровня формируются по типу задачи отдельно от готового решения. Полный ответ появляется только на третьем уровне. После ошибки решение также открывается по кнопке.

Просмотр решения после уже отправленного ответа не изменяет результат задним числом. Помощь до проверки не засчитывается как самостоятельное решение. Общая памятка дробей в самостоятельной тренировке также считается помощью; чтение памятки в уроке и изучение карточек с ответами не создают ошибку.

## Сохранение и совместимость

Рекорды и число тренировок из `math-sprint/progress/v1` переносятся без выдумывания подробной статистики старых ответов. Новые записи используют `math-sprint/progress/v2`; прежняя запись не удаляется. Записи результатов выполняются последовательно, повторные нажатия не дублируют попытку или завершённую сессию. При ошибке записи доступна кнопка повторного сохранения; при ошибке загрузки приложение не перезаписывает существующие данные пустым прогрессом.

Автоматические тесты проверяют миграцию, сохранение незавершённой тренировки, интервалы, сброс закрепления, подсказки, уникальность охвата, короткие повторы, все банки подсказок и порядок записей. Сценарии интерфейса проверены в мобильном веб-представлении на ширинах 390 и 320 пикселей: обычная десятка, помощь, двухзадачный повтор, будущая очередь, перезагрузка, прогресс групп, памятка дробей, отдельный практический вопрос и повтор сохранения после сбоя. Проверка на физическом Android-устройстве остаётся отдельным этапом.
