# Десять готовых вариантов ОГЭ каждую неделю

Вход: «Пробный экзамен ОГЭ» → «Варианты этой недели». Доступны варианты 1–10, каждый содержит все задания №1–25. В карточке указаны номер, сюжет №1–5 и состояние последней сохранённой попытки. Можно решать с прежним таймером 235 минут или без ограничения времени. Ответы и разбор открываются после сдачи; оценка второй части остаётся ручной.

## Недельный календарь

Новая десятка появляется по понедельникам в 00:00 по Саратову, UTC+4. На экране показаны начало и конец недели. Один календарь применяется ко всем ученикам независимо от часового пояса телефона. Карточки обновляются в открытом приложении и при возвращении из фона.

Подборка вычисляется из встроенной базы по дате понедельника и версии алгоритма, без персонального прогресса и случайности устройства. Поэтому «вариант 7 недели 19.10.2026» содержит одинаковые задания у преподавателя и учеников с той же версией банка. Интернет, сервер, регулярный push в GitHub и новая установка APK для еженедельной смены не требуются. Используется время устройства; при неверной дате телефона будет показана соответствующая ей неделя.

## Состав десяти работ

- Во всех вариантах номера идут строго №1–25.
- №1–5 берутся одним целым блоком: общий текст, рисунок, таблицы и пять вопросов соответствуют друг другу.
- В десятке представлены все восемь практических тем; две из них представлены дважды разными блоками. Дополнительные темы меняются с неделей.
- №6–19: десять вариантов покрывают все десять групп каждого соответствующего модуля.
- №20–25: используются прежние выбранные группы с полными решениями. Количество заданий из каждой подходящей группы сбалансировано с разницей не более одного.
- Внутри одной недельной десятки нет одинаковых задач. Соседние недельные подборки также не используют одни и те же задачи. Долгосрочная ротация достигает всех вариантов выбранных групп, а не постоянной части банка.

Это составленные из нашего банка учебные работы, не официальные КИМ. Соответствие всем типам официального экзамена не заявляется.

## Начатые работы и история

При старте копируется полный список 25 ссылок на задачи и метка недели/номера. Смена недели не пересобирает уже начатую работу: ответы, черновики, отметки и таймер остаются прежними. Незаконченная работа не заменяется другим вариантом. Её можно продолжить из верхней карточки, даже если её неделя уже закончилась.

После сдачи на карточке варианта появляются результат первой части и ссылка на разбор. При ручной оценке всех шести задач также показывается учебный итог. Можно пройти тот же фиксированный вариант ещё раз: задания будут прежними, ответы — пустыми, попытка — отдельной.

История расширена до десяти предыдущих работ плюс текущая, чтобы все десять вариантов помещались одновременно. История ограничена этим числом; новые попытки постепенно вытесняют самые старые полные работы. Перенесённые в рабочую тетрадь решения остаются там независимо от истории экзамена.

Дополнительный случайный вариант доступен ниже недельной десятки и не меняет её состав. Прежние работы и прогресс переносятся без сброса.

## Проверки

`tests/weekly-exam.test.ts`: граница понедельника UTC+4, переход года, полный состав и связность №1–5, сотня недель без повторов в соседних подборках, разнообразие групп, достижимость всех вариантов за 120 недель, одинаковый результат в отдельных процессах с разными часовыми поясами, снимок начатой работы после смены недели и перезапуска, сохранность всех десяти сданных работ, ручная оценка и интеграция очередей, неверные метки и миграция. Контрольная сумма набора 19.10.2026 фиксирует алгоритм версии 1; изменение состава должно быть осознанным.

Интерфейс проверяется на мобильной ширине, включая смену недели в открытом каталоге, продолжение старой работы, старт варианта новой недели и случайный дополнительный вариант.
